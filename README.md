## 🗂️ Project Tasks

### 📌 Task 1: To-Do List App  
A simple command-line to-do list manager that lets users add, update, delete, and view tasks. It’s designed to help users manage daily tasks efficiently in one place.

### 🧮 Task 2: Basic Calculator  
This calculator performs basic arithmetic operations — addition, subtraction, multiplication, and division. Users can input two numbers and choose the operation they want.

### 🔐 Task 3: Password Generator  
A Python script that generates secure and customizable passwords based on user input. You can set the password length and whether to include numbers, symbols, uppercase, or lowercase letters.

### ✊ Task 4: Rock-Paper-Scissors Game  
A fun, interactive game where the user plays rock-paper-scissors against the computer. The game can be played in multiple rounds and includes a simple, friendly interface.

### 📇 Task 5: Contact Book Application  
A lightweight contact management system where users can add, search, update, and delete contacts. Each contact entry stores a name, phone number, email, and address.
